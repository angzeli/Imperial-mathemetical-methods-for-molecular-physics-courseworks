# Mathematical Methods for Molecular Physics – Courseworks

This repository contains my completed **Coursework 1** and **Coursework 2** for the *Mathematical Methods for Molecular Physics* module at **Imperial College London**.

The work focuses on analytical techniques commonly used in molecular physics, including asymptotic expansions, Fourier analysis, scaling arguments, contour integration, and approximate solution methods for transcendental equations.

## 🧮 Coursework 1 — Overview

**Topics covered**
- Maclaurin and Taylor expansions
- Asymptotic behaviour of functions
- Approximation of integrals
- Solving transcendental equations
- Physical interpretation of approximations
- Lennard–Jones potential and molecular vibrations
- Thermodynamic derivatives and equations of state

**Features**
- Full analytical derivations in LaTeX  
- Python scripts for numerical integration and plotting  
- Direct comparison between analytical approximations and numerical results

## 📐 Coursework 2 — Overview

**Topics covered**
- Fourier transforms and frequency spectra
- Delta-function limits and Lorentzian broadening
- Fourier transforms in three dimensions
- Scaling analysis in quantum mechanics
- Transport phenomena in electrolytes
- Chemical kinetics and mean-free-path arguments
- Lagrange and Newton methods for solving equations
- Laplace’s method for asymptotic integrals
- Contour integration and residue theorem

**Highlights**
- Careful scaling arguments with dimensional analysis  
- Rigorous contour integration using rectangular contours  
- Clear physical interpretation of asymptotic limits  
- Consistent comparison with lecture perturbation results
